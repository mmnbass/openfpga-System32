## Analogue Pocket openFPGA framework (core template; fetched by the build, not included here)

The build fetches Analogue's core template from `https://github.com/open-fpga/core-template` at the pinned revision `da3a021b1eaf742604d86d8dc9b33a6666263e6a` (v1.3.0). Its `src/fpga/apf/` files and `src/fpga/core/core_bridge_cmd.v` go into the bitstream.

- **No repository licence:** the template has no LICENSE file at that revision. Its README has a "Legal" note about the development
  programme.
- **APF files** (`apf_top.v`, `common.v`, `io_bridge_peripheral.v`, `io_pad_controller.v` and others): each carries Analogue Enterprises
  Limited's "Software License Agreement". It licenses the APF for creating applications for Analogue's products, refers to the
  Analogue EULA, and states that where use of the APF requires the MIT License or the GNU General Public License, the terms of those
  licences prevail over inconsistent APF terms.
- **Megafunction wrappers** generated by Intel Quartus (`mf_*.v`): Intel's notices are in their headers.
- **This repository's `core_top`** (`experiments/U1-universal/rtl/derived/d2_core_top_rel.sv`): its port list and safe pin defaults
  follow the template's `core_top.v` skeleton. The rest is this project's code.
